04 / MODEL

반출부터 반납까지
모든 작업을 끝내야 유효합니다.

반출 p→적출 시작 u→공컨테이너 반납 r

작업 순서와 기한

  • 통관/방출 가능일 ≤ p ≤ u
  • 적출 종료 ≤ 화물 인도 기한
  • 적출 종료 및 명시된 지연 ≤ r < 계획 종료

하루 자원 사용

  • 반출·반납 각각 운송 1회
  • 적출 기간 창고 슬롯 1개
  • 반출일부터 반납 전일까지 대기 슬롯

min Σ (PNC 보관료 + D&D − 계획 전 고정 발생액)

고정 발생액 차감은 일정의 최적 순서를 바꾸지 않습니다. 모든 상자를 검산한 완전 일정만 비용 비교에 들어갑니다.
