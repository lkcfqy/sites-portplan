# V2 保守缓冲计划：探索性成本与可行性权衡

**在观察静态原计划18次固定扰动检查中16次失效之后设计的探索性实验。** 不是主48案例预注册实验的一部分，不能解释成独立确认性发现或随机失效率。协议先于本实验运行冻结；SHA-256：`96c01c0b7d55da6b60cf88c14d8de23a1313888deed3b6a7e2607870e7d669d5`。原计划读取已有运营压力数据，不重选。

## 固定规则

相同6个root种子，所有箱卸货时长加1天，整个周期每天运输能力预留2箱次，其他输入保持。没有先看具体故障日期或受影响箱再选择缓冲。2秒MILP预算/例；计划事件日期一旦选定，在名义、最坏情况和三种扰动检查中保持不变。

在6个双方完整可行的配对案例中，额外费用合计4,652,550韩元，相对原完整两费合计14,408,650韩元为**32.29%**；相对原规划期增量费用合计6,051,550韩元为76.88%。这是合成订单、公开标准费率下的模型成本，不是观察到的实际成本，也不包括运输/人力等其他成本。两种百分比的分母不同。

原排程在18次固定扰动检查中16次失效；找到的保守排程在18次同类检查中0次失效。三次检查复用同一场景，**不按独立随机样本计算失败率**。共54次检查由另行实现的auditOperations复算实际卸货末日和全部操作约束，不依赖保存的unloadEndDay。

## 可保证的范围

若保守计划完整可行，且每箱实际卸货时长介于名义值与名义+1天之间、每一天实际运输能力不低于max(0,名义−2)，其他输入不变，则固定计划在这套静态日粒度约束中可行。这来自单调包含关系：任何范围内实际装卸占用区间都不长于规划的最坏区间，实际运输容量不低于规划容量，提/卸开始/还箱日期不变。仍需业务核实费用合同、日内路线与时窗。

**不是线上滚动调度，不覆盖到港/放行延误、两天以上装卸延误、更多运力损失、仓库或场地容量变化。** 不保证真实业务或范围外扰动。保守模型不可行或超时时，没有可保证的计划；这也是必须展示的代价。
