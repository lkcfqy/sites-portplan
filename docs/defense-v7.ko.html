05 / EXTERNAL METHOD

고전 GRASP를 같은 PortPlan 모델에
명시적으로 적응했습니다.

RCL = {e : g(e) ≤ gmin + α(gmax−gmin)}
α=0.25 · 자원 영향 가중 0.15 · 다중 구성 + 국소 개선
  • 현재 합법 날짜 trip의 비용·자원 점수로 RCL 구성
  • 무작위 구성과 제한 first-improvement 단일/쌍 이동
  • 최대 128 구성 시도, MILP 없이 완전 후보만 보존
  • Resende–Ribeiro 공개 보고서 및 MIT 참고 코드 귀속
문헌의 고전 framework를 적응한 기준선입니다. 원 항만 논문 재현·원 ALNS·SOTA·최초 방법이 아닙니다.
