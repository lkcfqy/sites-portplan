## 完成范围

本版明确以公开来源完成项目，不以找企业、获取私有合同或请人证明为前置条件。所有源数据、代码、算例和归档结果可在线取得或随源码复现。

| 研究问题 | 已取得的证据 | 结论范围 |
|---|---|---|
| 收费公式是否与刊载数值一致 | 2个官方明确算例及11个另行标记的推导边界 | 已验证狭窄算例；Maersk跨档仍是解释假设 |
| 联合排程相对增强基准有何作用 | 48个不同合成订单集；全部结果与失败保留 | 36对新增费用降低15.74%；14对新到港没有收费差 |
| 留缓冲需要什么代价 | 6个基础情景、18个指定扰动的探索性试验 | 保守计划0次失效，增加32.29%总两费；仅指定范围 |
| 真实公开观测上的误差能否复算 | 58,171条光阳车辆访问、日历留出和独立复算器 | 6月9,152条MAE16.47分钟，基准16.88分钟；非PNC费用收益 |
| 外部论文代码是否可复现 | 原样6次失败；明确补件假设6次输出及结构审查 | 已完成复现审计，未声称完整费用/约束验证或超越原方法 |

## 竞赛论证

作品可完整陈述为：**公开收费机制驱动的港口提还箱决策与缓冲成本研究，附真实公开场内停留观测验证。** 收费、排程、观测与外部复现是四种证据，不能相互替代。

可主张公开来源可核验、建模可运行、条件性收益与失败可复现、缓冲代价透明。联合提还箱、拆箱与D&D已有研究先例，不能主张算法首创。真实公开记录属于光阳港，不能将其挂接为PNC箱级历史回放。

**自评：在全公开研究范围内，项目已形成可演示、可复算、可答辩的完整版本。** 比赛名次取决于评审和其他作品，不能通过本项目自评断言第一。后续补强继续遵守全公开条件，重点是更强同问题基准、清晰应用贡献及本人答辩掌握，而非向用户转移企业资料收集任务。
