# 真实公开闸口记录的时间留出验证

本模块不需要企业提供资料。原始数据来自光阳港西部码头公开车辆进出记录，共58,171条可解析观测；不是PNC箱级订单。目标是进入至离开闸口的场内停留分钟数。

## 冻结方法与结果

协议SHA-256：`633eb5b1c61b140da6e8f5252cf482900571be4f27b7fb6c5fde336730dc8b7e`。本研究是在已读公开汇总统计后设计的回顾性验证；候选方法在拟合前固定。1–4月训练（41,039条）、5月选模（7,980条）、6月测试（9,152条）。不随机打散时间，不使用测试期退出信息或全天流量作为输入特征。模型只使用进入时已知的小时和星期。

选中的方法是`hour_median`。6月平均绝对误差为**16.47分钟**；固定训练期全局中位数基准为16.88分钟。误差降低2.42%；负数也按原样保留。

| 预先声明的方法 | 5月MAE（选模） | 6月MAE（评估） |
|---|---:|---:|
| global_median | 18.483 | 16.877 |
| hour_median | 18.129 | 16.468 |
| weekday_hour_median | 18.154 | 16.499 |

6月中位绝对误差12.00分钟，P90绝对误差35.00分钟。观察到21个测试日期；逐日等权的MAE改善均值0.695分钟，日期区组bootstrap95%区间[0.302, 1.294]。这个等权日期指标与全部记录加权主指标的分母不同。

## 能支持的结论

这是一项真实公开观测上的后续月份误差验证，能检查公开数据支持的场内停留估计。对外报告必须同时呈现很小或为负的改善、缺失日期及尾部误差。模型未在现场部署，无法据此推断PNC费用、运输能力、仓库效率或节省收益。

所有车辆标识在建模和交付数据中删除。无稳定车辆ID，不能做车辆独立分组；表面重复记录保持原样。数据中缺失的日期不按零流量处理，韩国时间是位置推断而非CSV显式说明。

## 复现

`python scripts/public-gate-validation-v3.py --raw /path/to/official.csv`。省略`--raw`会从官方公开网址获取固定版本并校验SHA-256。完整无标识派生记录位于`data/public/v3-gate-visits-deidentified.csv`，候选指标和测试样例位于`data/public-gate-validation-v3.json`。
