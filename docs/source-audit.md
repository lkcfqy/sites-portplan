## 1. PNC收费：可核验的规则和未解决的冲突

[PNC 2026 Standard Tariff](https://www.pncport.com/resources/homepage/kor/data/2026_PNC_Standard_Tariff.pdf) 第3—4页给出普通干货进口规则。2026-01-01生效，金额KRW/TEU/日：总堆存1—4日免费；5—7日9,100；8—9日18,200；10—14日31,850；15日及以后45,500。

令 `d` 为按其规则计算的总堆存日、`u` 为TEU数：`storage(d,u)=max(0,d−4)×最高适用档单价(d)×u`。最高档单价追溯所有收费日，不能逐档累加。20英尺为1 TEU，40英尺为2 TEU；v1仅覆盖普通20/40英尺干货。日历日计数；卸船时刻严格早于08:00从卸船日开始，否则次日开始，至反出日均包含。当天反出且计费起点在次日时，天数截为0。07:59与08:00是必要边界测试。

官方算例：20英尺堆存15日，`11×45,500=500,500`。由公式推得14日为318,500，跨至15日增加182,000；这是费率机制算例，不是已取得的优化收益。

[PNC货主费用结算页](https://svc.pncport.com/info/CMS/Container/CostInquiry.pnc?mCode=MN177) 仍展示8,800 / 17,600 / 30,800 / 44,000。这与[2025正式PDF](https://www.pncport.com/resources/homepage/kor/data/2025_PNC_Standard_Tariff.pdf)的表格一致，与2026正式PDF不一致。页面同时说明显示值只是估算、实际以PLISM结算为准，合计标签包含VAT。不能据此推断货主必定享有另一份现行特殊价，也不能自行认定网页已更新。

**v1选择：锁定有生效日期的2026正式PDF作为公开基准，不模拟发票税额，不宣称所得金额为实际含税应付额。** 协议费率、账单税务、码头实时结算差异保留为部署前核对项。货主结算页通过web工具读取成功，执行器直接获取返回403；已保存事实摘录，未伪造原始HTML。2025 PDF自身第4页算例还与其44,000表格不一致，因此仅用该年的表格核对网页旧价，不把旧算例用于测试。

## 2. Maersk韩国进口combined D&D

[韩国进口官网](https://www.maersk.com/local-information/asia-pacific/south-korea/import)现行标准表与[2024费率调整通知](https://www.maersk.com/~/media_sc9/maersk/local-information/files/asia-pacific/korea/import/kr-exp-imp-dd-rate-jul-2024.pdf)一致：干货1—10日免费，11—15日20/40英尺分别15,000/30,000，16—20日30,000/50,000，21日及以后50,000/90,000；官网40英尺栏同时包含40HC和45H。

日历日从卸船日到空箱返回约定场站日，两端包含。内陆公路交付场景存在不同起点，v1不覆盖。2024-07-15是Pricing Calculation Date口径，不是简单按卸船日套新价；历史特殊合同有效期内可继续旧价，购入免费期和单票条款也应优先。

v1把该日费率表按每天所在档位累加，例如20英尺16日为`5×15,000+1×30,000=105,000`。**这是对分档日费率的实现解释；本次没有找到韩国官网明确的累加算例或明确写明“progressive”的本地条款。** 标记为待业务核实，不把别国Maersk计算规则当成韩国证据。正式报价前需核对MyFinance/单票合同。

[Maersk 2022-12-26 PNC通知](https://www.maersk.com/~/media_sc9/maersk/local-information/files/asia-pacific/korea/import/busan-port-import-storage-fee-imposition-process-change-information-26dec.pdf)明确自2023-01-01起相关进口仓储费由PNC按公开费率直接向进口方收取，与Maersk自身D&D分开。因此可以研究两项费用的联合优化；不能把其中一项替代另一项。

## 3. 实际取得的公开数据与质量发现

### 光阳港西部码头车辆进出

[韩国公共数据门户目录](https://www.data.go.kr/data/15059682/fileData.do)提供2026H1 CSV，下载无需个人凭据；目录标明使用范围不受限制。原件5,401,590字节，CP949编码。包含遮罩后的车牌、进入/离开闸口、进入/离开时间和工作时长。

| 核验项 | 结果及解释 |
|---|---|
| 文件记录数 | 226,217行，不含表头 |
| 全空行 | 168,046行，74.29%；剔除这些行后58,171行 |
| 有效时间对 | 58,171；非空行无缺字段，未发现解析失败或负时间差 |
| 覆盖期 | 2026-01-01至06-30，仅119个日期有记录；缺记录日不补零 |
| 完全相同非空记录 | 7条多余记录；遮罩车牌缺少稳定唯一键，不能认定同一车辆重复，保留并标记 |
| 闸口进出时间差 | 中位23分钟、p90 59分钟、p95 73分钟；nearest-rank分位数 |
| 原始工作时长一致性 | 与分钟分辨率进出差偏差超过1分钟的记录为0 |

风险：多数物理行为空；119天不等于181天全覆盖；遮罩车牌不能可靠追踪同一车；车辆访问不是箱级订单。时区Asia/Seoul由韩国码头位置推断，CSV没有时区字段。场内时间不等于公路运输或仓库卸货时间，也不能跨港推为PNC效率。

原件在`/tmp/portplan-source-cache/ygpa_west_2026h1.csv`；公共交付保留`ygpa_gate_statistics.json`和去掉全部车牌的`ygpa_gate_sample_200.csv`。200行按有效行位置等距选择，方便检查，不是随机代表样本。`data/public/profile_ygpa.py`可从原件重建二者。它们**未用于优化器需求或收益**。

## 4. 比赛与竞品核验

[2026官方报名页](https://anchor.changwon.ac.kr/main/menu?gc=Program&do=sinform&spod=s1&program_id=VKoDUNlZwONq&psin_id=VKoDUNlMqh4n)和海报一致：昌原大学在读学生（含研究生），4人以内团队；11月6日18:00材料截止、11月13日初审、11月20日展示；报告及数据/代码等一并提交，演示材料≤20页。页面40名、先到先得。**没有查到今年评分权重、明确单人资格下限、AI辅助边界或答辩时长**。第一名是대상（庆尚南道知事奖），최우수상是另一奖项，不能误把去年最优秀奖称为第一。

[2025学校获奖报道](https://www.changwon.ac.kr/ie/na/ntt/selectNttInfo.do?mi=13934&nttSn=1400175)描述了地点—路径优化、MILP与CPLEX；可作为技术完成度的参考，不能据此推断全部对手水平或今年获奖概率。

[Portcast官方计算器页](https://www.portcast.io/dd-tool/maersk-demurrage-and-detention)已有D&D计算、风险阈值和预警；[Maersk MyFinance](https://www.maersk.com/news/articles/2023/11/15/simplify-demurrage-and-detention)亦有单箱收费信息。PNC自身还有费用查询服务。因此“显示费用/做风险提醒”不构成充分新意。v1待验证的贡献应是：明确阶梯回溯机制，联合提箱—卸货—还箱与资源约束，公平对照基线并给出可执行排程。没有证据表明其他产品都没有这种能力，不能宣称全球首创。

## 5. 自评需要坚持的证据界限

可主张：公开规则核验、数据质量检查、可复現代码、同条件模拟中的比较结果。不可主张：实际为企业节省某比例、已通过PNC实单验证、官方认可本算法或有证据保证夺冠。拿第一所需的主要证据缺口仍是适用合同确认和足够完整的真实单箱历史，而不是再堆叠可视化功能。
