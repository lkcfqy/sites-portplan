# V12：公开来源字段覆盖与可验证问题

本交付完成已声明的有限公开来源字段审计：7个来源，41个不同的现存原件/目录/审核文件逐字节绑定，其中24个原件或目录的SHA与既有取证记录一致。另保留4份历史原始文件的既有路径、URL、字节数和SHA声明，本轮没有读取或重新下载：1份有标识gate CSV、3份PSPLIB数值原件。完整清单见 `data/public-source-field-coverage-v12.json`，每源都有原件、许可依据、原生单位、缺失字段、支持的问题与不支持的主张。

这项完成状态是来源覆盖交付的闭环，不是新增业务实验、第三方认证或完整港口模型有效性证明。本轮没有网络请求、求解器调用、拟合、bootstrap、SQL流程重建或新增订单。既有审核的结果、失败和适用范围保持原样；没有改动冻结算法或正式研究数据。

## 已有真实观测支持的问题

选定的问题是：**在光阳西码头，使用车辆入场时已知的小时/星期信息，能否降低后续月份车辆入场至出场时长的离线预测MAE？** 这是源数据原生的车辆visit问题；“原生数据”不表示原生优化器性能，也不表示完整集装箱提卸还验证。

YGPA公开观测的去标识版本保留58,171条记录。1—4月41,039条训练，5月7,980条在三种预声明候选中选模，6月9,152条测试。五月选出的 `hour_median` 六月MAE为 **16.468422分钟**；训练全局中位数基准为 **16.877185分钟**，按visit加权的MAE相对下降 **2.421986%**。所选方法六月绝对误差P90为35分钟，不能把较小的平均误差改写为“预测准确率97.6%”、车辆停留缩短或实际省钱。

六月有21个实际观测日期。按观测日期等权计算的MAE改善为0.695235分钟，日期bootstrap的95%区间为[0.302402, 1.293697]分钟。它的分母是日期，不能用来给上段按visit加权的0.408763分钟差值直接贴区间。缺失日期不补成零流量，掩码车牌也不能支持独立车辆样本假设。

V11已经从保存的去标识CSV独立重算分期、三种候选、误差、尾部、逐日差和1000次日期bootstrap；本轮只绑定该检查及其数值。V11没有重新认证原始有标识CSV与去标识行的转换关系。研究是回顾性探索；候选在拟合前固定，但此前已读过历史总体统计，不称前瞻部署试验。源CSV未明示时区，Asia/Seoul来自码头地理位置推断。

## 完整生命周期仍采用明确仿真

这7个来源没有一个同时提供箱级关联的卸船时间、放行、20/40ft箱型、硬卸货截止、提箱—连续卸货—空返、逐日三资源容量及实际适用合同费用。不能跨港口、散货/箱货、分钟/tick/天或不同目标拼成“真实全链箱单”。

PortPlan完整生命周期的算法比较继续使用公开规则下、可复现且明确标注的仿真；提箱/空返同日双运输、仓库连续占用、staging的箱或TEU单位、历史执行锁与沉没/增量两费口径，由对应模型及独立物理审核验证。这些是研究模型与记账约定，不是从gate或散粮日志观测出的全部业务事实。此字段审计不替代任何优化器或正式研究审核。

这不阻塞公开资料路线。已支持的真实观测问题、公开数学组件、官方规则检查与合成完整模型各有可交付证据；企业订单、私人合同或联系人仍为可选增强，不要求用户补齐后才继续开发，也不据此保证比赛名次。

## 只读复核

在项目根目录运行：

```sh
python scripts/check-public-source-field-coverage-v12.py
```

该脚本只读清单和现存仓库文件，检查固定7源、字段/单位/边界是否齐全、41个不同文件的字节数/SHA、24个既有收据匹配以及保存的gate数值绑定，报告输出到stdout。它不读取4份历史原始文件、不下载、不运行优化器或重新拟合，并明确不认证来源真实性或许可法律结论。故意修改清单绑定或文件字节会报错；需要恢复已冻结证据，不能用更新SHA掩盖变更。

如另需重做既有gate独立复算，可用 `scripts/verify-public-evidence-v11.py` 并指定新的输出路径；这不是本次覆盖检查的一部分。本次新增文件只整理范围和完整性，不新增预测/优化成绩。
