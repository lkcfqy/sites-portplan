04 / LIFECYCLE

반출·적출·반납을
모두 완료한 계획만 계산합니다.

반출 p→적출 u→공컨테이너 반납 r

작업과 기한

  • 방출 가능일 ≤ p ≤ u
  • 연속 적출 종료 ≤ 화물 기한
  • 적출 이후 반납·전체 기간 내 완료

같이 쓰는 자원

  • 반출·반납 각 운송 1회
  • 연속 적출일의 창고 슬롯
  • [p,r) 기간의 대기 슬롯

min Σ (PNC 보관료 + D&D − 계획 전 고정 발생액)

05 / V4 TO V5

V4에서 확인한 약점으로 개발하고,
새 seed에서 다시 비교합니다.

V4는 개발 근거

전처리 결합의 공정한 예산 비교는 직접 날짜 탐색보다 더 높은 합산 요금을 보였습니다.

이를 숨기거나 V4 최저 사례를 대표 성과로 선택하지 않습니다.

V5는 새 생성 seed

정적 36개, 별도 실행 24개 새 경로에서 고정 정책을 평가합니다.

같은 합성 생성 메커니즘 안의 seed 분리입니다.

외부 기업 주문·실제 운영 기간·다른 생성 분포의 일반화 검증은 아닙니다. V4 결과와 V5 결과의 분모를 섞지 않습니다.
