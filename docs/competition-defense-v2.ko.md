# PortPlan V2 — 한국어 요약 및 용어 보조

주 발표·질의응답 자료는 [`competition-defense-v2.en.md`](competition-defense-v2.en.md)의 영어판이다. 영어 발표 허용 여부와 공식 발표시간은 아직 확인되지 않았다. 공개 참가 안내는 재학생에 대학원생을 포함하지만, 개인 참가 최소 인원과 AI 활용 경계는 별도 확인이 필요하다. 이 문서는 주최 측 승인이나 제출 완료 기록이 아니다.

## 간단 요약

PortPlan은 PNC 2026 공개 보관료의 소급형 단계요율과 Maersk D&D를 연구용 비용 기준으로 사용하여, 수입 컨테이너의 반출·창고 적출·공컨테이너 반납 일정을 일별 자원 제약 안에서 함께 결정하는 시제품이다. 요율의 출처는 실제 공개 자료이며, 실험 주문과 용량은 합성 조건이다. 광양·인천 공개 게이트 자료는 PNC 주문이나 절감 검증자료로 사용하지 않았다.

통합 컨테이너 일정계획과 D&D를 다룬 선행연구가 있으므로 최초의 통합 최적화 알고리즘이라고 주장하지 않는다. 기여는 지역 요율의 정확한 구현, 감사 가능한 일정, 강한 비교방법과 실패 사례까지 공개하는 재현 실험에 있다. 실제 계약 적용과 현장 실행 가능성은 아직 별도 검증이 필요하다. V2의 36개 완전 실행 가능 비교쌍에서 모형 비용 차이는 20,073,600원으로, 증분비용 기준 15.74%, 총비용 기준 8.86%였다. 신규 도착 14개 비교쌍은 양쪽 모두 비용이 0이었다. 추가 교란 검사에서 원래 정적 계획은 18회 중 16회 실행 불가능해졌다. 탐색적 보수 계획은 지정한 18회 검사를 통과했지만 총비용은 32.29% 증가했다. 이는 명시된 일별 불확실성 범위의 비용·실행 가능성 절충이며 온라인 복구나 실제 기업 성과가 아니다. 상세한 실패 사례와 검증 범위는 영어판 결과표를 따른다.

## 용어

| English | 한국어 | 中文说明 |
|---|---|---|
| Vessel discharge | 양하 | 船上卸箱；区别于仓库卸箱内货物 |
| Terminal pickup / gate-out | 반출 | 提箱/出闸 |
| Devanning / unloading cargo from container | 적출 | 仓库将货物从箱内卸出 |
| Empty return / gate-in | 공컨테이너 반납 / 반입 | 空箱归还指定场站 |
| Terminal storage charge | 터미널 보관료 | 与具体船公司D&D适用关系须核对 |
| Retroactive highest-bracket rate | 최고 도달구간 요율의 소급 적용 | 最高到达档位追溯适用收费天数 |
| Daily transport-movement allowance | 일별 운송작업 한도 | 作业次数，不是卡车台数 |
| Staging capacity | 장치 공간 용량 | 模型箱位；按箱或TEU须明确 |
| Complete feasible schedule | 모든 주문을 포함한 실행 가능 일정 | 必须全订单、满足模型约束 |
| Proven model infeasibility | 모형의 실행 불가능 판정 | 与启发式失败/超时区分 |
| Tariff-based prior reference amount | 계획 전일 요율 기준액 | 不是已付款或会计沉没成本 |
| Synthetic scenario | 합성 시나리오 | 不得包装为企业实测 |

## AI·오픈소스 공개 요지

GLPK/glpk.js 등 기존 소프트웨어와 AI 보조 도구의 사용 범위를 기여 기록에 명시한다. 제출자는 실제로 수행하고 검증한 부분만 본인의 기여로 설명하며, 자료·가정·코드·실험 결과를 직접 설명할 수 있어야 한다. 아직 확인하지 않은 대회 정책을 허용받았다고 주장하지 않는다.
