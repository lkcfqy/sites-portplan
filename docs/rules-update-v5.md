## V5 优势的待验证门槛

本轮没有新增官方评分依据，因此开发继续按已发现的技术缺口推进。V4 合成预处理政策的同预算配对成本高于直接日期搜索，不能在 V5 中只换算法名称后删除负结果或沿用旧百分比。

1. **更早取得完整候选是否改善执行可用性：** 使用在 V5 运行前冻结的完整面板、所有方法相同端到端预算，统计检算候选收到时间、完整可行数、无候选和超时。不能把部分订单或过期返回计成功。
2. **候选质量与计算开销是否真正改善：** 保留 V4 直接日期搜索和基本 MILP；不同的新初解、构造、搜索及回退耗时全部计入比较。费用只在完整配对上比较，零费用、负差和缺配对不删除。
3. **策略选择能否在未来信息未知时执行：** 若增加滚动策略，保持相同观测及历史冻结语义，明确所有初始订单已知；调用次数不同就不声称总 CPU 相同。prefix 信息一致性与历史不可逆检查继续保留。
4. **更强结论是否有独立支撑：** 新候选经过独立费用/容量复算；静态证书与滚动历史审核分别说明；浮点容差状态不得升级为精确证明。

这些是待实验检验的研发条件，不是预报 V5 会获胜。V5 韩文报告和展示应由最终方法、冻结协议和实际结果重新生成，保留 V4 负结果作为迭代动机，并继续真实披露 AI 自主完成的贡献；当前没有用预计数值改写旧材料。
