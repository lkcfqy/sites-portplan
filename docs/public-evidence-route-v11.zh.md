## 五类离线检查怎样解释

1. **光阳港公开观测独立复算。** 从保存的去标识CSV读取58,171条记录，独立实现训练期全局、小时、星期×小时三种中位数方法。1—4月训练、5月选模、6月测试；核对各期数量、候选误差、所选方法、尾部误差、逐日差及1000次日期bootstrap。六月9,152条记录，所选小时模型MAE为16.468422分钟，基准16.877185分钟。原始有标识CSV不需要交给新电脑；缺失日期不补零。该检查不重新证明去标识过程与原始行之间的对应关系。
2. **费用实现运行。** 执行当前产品的13项检查，2项官方刊载例与11项本项目推导边界全部数值一致。费用函数和既有独立结构参考算式来自项目代码，本项明确不是第三份独立费用实现。Maersk第一档官方例仍不能解决韩国跨档计价解释。
3. **PLOS公开代码与历史结果绑定。** 核对原件、原函数AST、输入、协议和12条保存结果。原文件轨道6条运行错误；明确假设`distance2 := distance`的另6条有返回值但费用仍未独立认证。检查通过表示失败和未验证状态被完整保留，绝非复现了论文完整预算或证明PortPlan优于论文。
4. **PSPLIB保存审核与资源台账绑定。** 检查已有审核、480份保存资源台账、对应结果和16项输入绑定。原始PSPLIB数值缓存不在本项重新下载、解析或运行，不能称作本轮重新验证了资源排程可行性或最优参考值。它也不能替代港口提卸还完整模型的外部验证。
5. **V10冻结证据链。** 核对144个场景、2160条记录、2304个输入/结果原档字节、两份保存审核、协议及135份冻结源码。现行开发文件与冻结版本的差异另列，不能替换冻结实现。这里重新检查的是完整性绑定，没有再次运行求解器、全量物理审核或统计重抽样审核器。

五项检查通过是五种有限检查通过，不能解读为五个独立业务效果实验。报告记录每项`kind`、`scope`、来源路径、字节数与SHA，并对缺失、篡改、路径越界和非有限数报错。

## 离线复现入口

先按恢复指南取得最新Git，或核对下载清单并合并全部分包。安装Node.js 24、npm及Python 3，终端中`python`应指向Python 3。以下只恢复已有原档和运行检查，不生成新订单、不覆盖首次结果：

```sh
npm ci
python scripts/restore-evidence-v8.py
python scripts/restore-evidence-v9.py
python scripts/restore-evidence-v10.py
python scripts/verify-public-evidence-v11.py --output artifacts/public-evidence-recheck.json
node scripts/check-commitment-v11.mjs --output artifacts/commitment-endpoint-recheck.json
```

两种检查器都要求新的输出路径，已有记录不覆盖。公开检查器使用Python标准库和Node，不需要GPU、网络或私人资料；端点集成使用明确标注的测试响应服务，不运行真实HiGHS优化。

研究原生HiGHS的重新求解另需`requirements-research-v4.txt`。实际重跑使用归档内的冻结runner、独立新输出目录及原协议，保留失败。限时结果受机器和运行环境影响，不能承诺另一电脑逐条状态完全一致。

## V11方法开发与尚未完成的工作

新的同费选择机制比较“执行今天动作后，明天最低必需卸货仓位”。已见D4全24箱案例中，三个重复的缓存M均为2，新候选M均为1，费用均为0；评分使用D4当时的公开名义次日容量3，没有使用后来D5才获知的容量1。必要下界更小只是开发动机，不能证明整个多资源路径可恢复。

V11只在费用相同容差内、双方评分完整及时且M严格更低时允许替换；省费、高费、失效缓存与时限语义另行保留。方法说明和独立负例分类见`docs/next-iteration-v11.zh.md`。初始无及时完整解的问题仍然存在，不能由同费选择机制宣称解决。

下一阶段按以下门槛推进：

- 在已见资料上做同一物理前缀的受控完整延续，保留成功、失败和变差。当前只有归档端点与模拟响应集成，尚未完成这项重放。
- 单独改进D0及时完整初解覆盖；V10相对V7有15次D0损失，其中12次候选接纳迟到、3次无incumbent。它们和后续固定前缀不可行是不同问题。
- 研究同港口模型的独立CP-SAT强基准。现有官方参考仅用于设计，尚未实现或运行，不预设更强；PSPLIB通用组件结果不能替它背书。
- 方法确定后再冻结新协议、实现与未见订单种子，进行公平正式比较。开发样例不能重新包装成新留出。V10的默认替换门槛仍未通过。
- 完成受支持浏览器的真实交互检查，以及参赛者本人复现、讲解和手续核对。当前缺少浏览器入口，代码、构建和文件检查不代替实际点击；AI不替本人填写通过。
